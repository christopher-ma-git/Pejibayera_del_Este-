=================== Software Necesario ===================
1. Descargar XAMPP (Servidor local para visualizar páginas web)
2. Descargar MySQL Workbench (Espacio de trabajo para Base de Datos <BD>)
3. Descargar Visual Studio Code (Editor de codigo de su preferencia)
4. Ingresar a Github (Obtener el repositorio del proyecto)

=================== ASPECTOS NECESARIOS ===================
    Para visualizar el trabajo debe clonar el repositorio en un folder dentro de la dirección:
"\xampp\htdocs".
    Encender XAMPP como administrador.
    
    Abrir MySQL Workbench y pegar el código de /database.sql completo, y ejecutarlo
